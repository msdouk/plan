# Plan de lotissement ENGUITRACI-Sarl

Page publique permettant aux clients de localiser leur parcelle sur le plan d'ensemble.

- Adresse : https://msdouk.github.io/plan/
- Lien direct vers une parcelle : `https://msdouk.github.io/plan/#p=<identifiant>`
- Mise à jour : remplacer `plans.js` (généré depuis l'application, Synthèse > Données > « Plan public pour les clients »).

Aucune donnée personnelle (nom, prix, paiement) n'est publiée.
